Angular component library · Portfolio project

A design system for the moments that can't wait

Aurora UI is an accessible Angular library for real-time hospital dashboards — bed occupancy, patient status and vital signs, readable at a glance. It is inspired by the dashboards Elvio Marcos Faria Junior designed and built for a hospital in Brazil. Aurora Hospital is a fictional brand; every name and reading on this page is invented.
