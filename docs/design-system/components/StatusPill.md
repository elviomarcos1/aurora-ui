# StatusPill

Shows a patient's clinical state with colour, an icon shape and a word, so the state reads without colour.

| Variant | Shape | Label examples |
|---|---|---|
| `critical` | triangle | Critical, Code blue |
| `warning` | diamond | Observation, Fasting |
| `stable` | circle | Stable |
| `info` | square | Discharge pending, Transfer, Scheduled |

Never use a pill without its label. Keep labels to one or two words. Colours come from the matching `-soft` background with the strong tone for text (5.5:1+ in both themes).
